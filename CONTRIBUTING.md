# Contributing

Thanks for considering a contribution!

1. Open an issue describing the bug or proposed feature.
2. Keep changes focused and document user-visible behavior.
3. Test inside the Blender version you claim to support.
4. Include reproduction steps for bug fixes.
5. Submit a pull request with a clear summary and screenshots where useful.

Do not include copyrighted assets or credentials. Do not claim test coverage or compatibility that has not been verified.
