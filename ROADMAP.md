# Project roadmap

This roadmap describes candidate work, not promised release dates. Please open an issue to discuss scope before starting a large change.

## Near-term priorities
- [ ] Test and document supported Blender versions.
- [ ] Improve operator context handling and error messages.
- [ ] Add real Blender integration tests where a Blender binary is available.
- [ ] Add configurable decimation and LOD naming presets.
- [ ] Add texture/image size reporting without modifying source images.
- [ ] Add repeatable batch FBX export settings.

## Community priorities
- [ ] Collect workflow feedback from Blender artists and game developers.
- [ ] Review and triage incoming issues.
- [ ] Publish versioned releases with clear notes.
- [ ] Document limitations and known issues.

## Contribution guidance
Small, focused pull requests are welcome. Please discuss substantial changes in an issue first. All contributors must follow the project license and avoid submitting assets they do not have permission to share.
